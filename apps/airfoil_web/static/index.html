Solver settings

The default low-speed solver creates the mesh and saves final fields.

Low-speed CFD uses an incompressible pressure-based solver with fully turbulent SST in free air. CPU execution uses the configured thread count; GPU execution is optional. Mach is ignored. The solver remains in development; inspect mesh quality and convergence.

GPU (CUDA), opt-in: the mesh is built on the CPU and shown first; the run then waits for the shared GPU lock (the job status says who holds it) and marches on the GPU with the solver's adopted CUDA speed settings (Float64). The CPU remains the default.

Defaults: Tu 1%, μt/μ 10. Looser steady limits may stop earlier; inspect mesh quality, residuals and loads before interpreting coefficients.

Choose D3Q27 + cumulant or D3Q39 + entropic. The pinned solver accepts up to 7 periodic-Y AMR levels when the domain, span, and memory permit. D3Q27 uses a fixed low-Mach carrier; D3Q39 uses the Mach input and compressible thermal flow. Both run on the GPU on the section extruded along a periodic span. Higher-level D3Q39 AMR and airfoil predictions are development paths; inspect mesh, interfaces, and convergence.

Smart stop checks residuals and load history over two windows, then waits 20,000 more iterations.

Tunnel walls reproduce the cavitation validation setup. Free fluid has far boundaries and no air/water free surface.

Experimental inviscid startup: nonlinear water/air/vapor interface with gravity. No SST, viscosity, energy equation or phase change. Results do not qualify cavitation, drag or stall parity.

Projection advances the nonlinear interface on a convective/gravity timestep. Pressure loads remain experimental.

How to run a case

First choose the solver, above the steps. Every step then shows only what that solver uses.

  1. Airfoil: open a coordinate file or pick a section. A Gurney flap is added here.
  2. Flow: set Reynolds number and angle, Mach where the solver uses it, and a sweep for a polar.
  3. Mesh: choose the resolution. Create mesh shows the mesh that Run will use.
  4. Solver settings: method, GPU and stopping limits. The defaults suit an ordinary run.
  5. Run and outputs: choose the saved files, then Run analysis.
  6. Results: check Diagnostics before using forces or fields.

Each step ends with its action. Advanced groups hold rarely needed settings; they stay closed unless a loaded study or preset uses one.

Implicit Newton (CPU): a steady method of Compressible CFD, chosen in Solver settings. It runs steady compressible cases on the CPU in minutes per case, for a sharp or a blunt trailing edge, always on the Marched regular mesh. Development result, not validated.

How to run a case

First choose the solver, above the steps. Every step then shows only what that solver uses.

  1. Model: load an STL, OBJ or GLB file, then scale, rotate and place it. A saved study is opened under Study.
  2. Domain: choose free air, ground or a symmetry plane, and the clearances around the model.
  3. Flow: set the angles, speed and fluid, and the reference area and chord for the coefficients.
  4. Mesh: set the surface cell size and the number of levels, then Create mesh. Inspect the mesh and the memory estimate.
  5. Run and outputs: set the run length, the output folder and the saved files, then Run solver.
  6. Results: show surface fields, recorded planes, images and coefficients. Saved result files can be read here without a run.

Each step ends with its action. Advanced groups hold rarely needed settings and stay closed. Changing steps 1 to 4 after a mesh exists needs a new mesh; step 5 does not.

Results of a completed run are instantaneous saved values: a finished run is not evidence of convergence.

      Reading the 3D view

      Domain axes stay fixed. Model axes follow the geometry rotation. Teal arrows show the prescribed inlet flow. Gold arrows show computed velocity from the selected recorded plane; their lengths are scaled for display. The i button lists inlet, outlet, and wall or far-field conditions; the domain faces are shaded by their role. Ground cases use solver Y as the vertical axis; other cases use Z.

      Under Display, Mesh levels shows each level as block outlines, cell outlines or translucent cells. Large volume displays are sampled. The section uses actual cell sizes and omits coarse cells covered by finer levels. Drag the border of the movable section or use its slider under Display; fields at arbitrary positions require a saved full-volume VTK snapshot. Inspect the cell size, wall coverage and memory summary before running.

# Start here

1. Download and extract the complete repository, keeping its folders together.
2. Run **setup at the repository root**, using the instructions for your system.
3. Launch **OpenAeroLab** from the matching folder below, then choose a workbench.

- [Windows](Windows/README.md)
- [Linux](Linux/README.md)
- [Mac](Mac/README.md)

Each folder also has an Airfoil Lab launcher for standalone use. Prefer
OpenAeroLab when switching between 2D and 3D workbenches. The terminal belongs
to the local server: keep it open while using the application. Closing a launcher
that reports it is reusing an existing server does not stop that server.

Re-run setup after updating the repository. Studies and results are local files
and are not part of a repository update.

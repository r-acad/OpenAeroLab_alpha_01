Solver

JXfoil provides coefficients and surface pressure. Flow fields require CFD.

See the complete solver guide for each method, application, maturity, and research paths that are not selectable here.

Low-speed CFD is the new incompressible pressure-based solver (version 2, in development, not yet validated): fully turbulent k-omega SST in free air, on the CPU (8 threads) by default or, opt-in, on the GPU. Mach is ignored.

GPU (CUDA), opt-in: the mesh is built on the CPU and shown first; the run then waits for the shared GPU lock (the job status says who holds it) and marches on the GPU with the solver's adopted CUDA speed settings (Float64). The CPU remains the default.

Defaults: Tu 1%, μt/μ 10 (freestream turbulence for a fast steady start). About 15-25 minutes per angle on this machine (alpha 0 about 35; each angle may run up to 60 minutes); the loads settle well before the steady stop.

Choose D3Q27 + cumulant or D3Q39 + entropic. The pinned solver accepts up to 7 periodic-Y AMR levels when the domain, span, and memory permit. D3Q27 uses a fixed low-Mach carrier; D3Q39 uses the Mach input and compressible thermal flow. Both run on the GPU on the section extruded along a periodic span. Higher-level D3Q39 AMR and airfoil predictions are development paths; inspect mesh, interfaces, and convergence. D3Q19 remains retired.

Advanced CFD controls

Smart stop checks residuals and load history over two windows, then waits 20,000 more iterations.

Mesh contours use equations for NACA sections and a smooth C² reconstruction for coordinate files.

Tunnel walls reproduce the cavitation validation setup. Free fluid has far boundaries and no air/water free surface.

Experimental inviscid startup: nonlinear water/air/vapor interface with gravity. No SST, viscosity, energy equation or phase change. Results do not qualify cavitation, drag or stall parity.

Projection advances the nonlinear interface on a convective/gravity timestep. Pressure loads remain experimental.
